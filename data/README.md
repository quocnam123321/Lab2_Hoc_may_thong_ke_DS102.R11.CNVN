# Dữ liệu MNIST

Chạy notebook `00_chuan_bi_du_lieu_MNIST.ipynb` để tải dữ liệu từ nguồn trong đề, sau đó tạo `mnist.npz`.

Giữ nguyên tập 60.000 ảnh train và 10.000 ảnh test. Các notebook mô hình chia pixel cho 255.0, không chia lại tập dữ liệu.

Các file nén và `mnist.npz` được bỏ qua trong Git để repository gọn hơn. Khi tải bài từ GitHub, cần Internet trong lần chạy notebook 00 đầu tiên.
